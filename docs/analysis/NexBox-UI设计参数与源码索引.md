## 1. 使用说明

这是从现有实现提取的观察清单，不是项目作者发布的正式设计规范，也不是一份已验证的跨端 token 包。

- CSS px、窗口逻辑尺寸、截图像素与 Android dp 分开记录。
- Chakra 空间、圆角、字体 token 保留原名，避免把默认库映射误当作项目的硬性约定。
- 组件 props、用户配置、系统主题和背景合成会改变最终样式。
- 所有数字均为源码值或明确标注的图片采样，运行表现未实测。
