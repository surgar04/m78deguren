## 统计与解释

从 [optimizerItems 配置](https://github.com/MuLiuSaMa/NexBox/blob/e7ad6a0bb9197e206bb9a719ca86c6353a5cad43/src/config/system-optimizer.ts#L108) 按数组顶层对象计数，共 **201 项、11 类**。一个下拉配置项只计一次，不把它的选项重复计算。中文名称来自 zh.json；风险“低/中/高”沿用项目自身标签，不代表本报告已经验证安全性或性能收益。配置标签合计：低 123、中 68、高 10。

应用通过 aq_registry 中的 .reg 文件，恢复通过 aq_registry_restore 中的 .restore.reg 文件。恢复是执行仓库给定的恢复值/删除项，不能据此认定能还原用户修改前的任意原始状态。win32Priority 为特殊下拉项：应用按所选变体读取文件，恢复使用统一的 win32Priority.restore.reg。

本次检查对应应用文件（含下拉变体）与恢复文件均存在；这里只检查资源对应关系，没有写入注册表，也未验证不同 Windows 版本对这些键的实际支持。
