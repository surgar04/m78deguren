## 已实测交互与边界

- 最近60/30/15秒切换；30秒窗口报告包含31个边界内样本。
- CPU/GPU/内存曲线显隐；图表左右方向键、Home/End定位采样，悬浮/键盘提示显示同一数组中的读数。
- 总览/设备信息/实时监测页签可点击，支持箭头/Home/End和roving tabIndex，aria-selected对应内容。
- 传感器弹窗显示真实派生的最小/最大值，未知风扇读数显示—；Escape关闭并恢复触发器焦点。
- 导出预览包含来源、版本、快照与选中时间窗完整序列；没有截断样本。
- 复制按钮的Clipboard API返回成功并显示已复制；Browser Use虚拟剪贴板未反映系统剪贴板，端到端粘贴未验证，不把此项描述为已读回剪贴板成功。
- 原生保存命令只接收JSON内容，在阻塞任务中写固定D盘reports目录；Rust测试实际写出并读回JSON，同时验证C盘、相对路径与包含父级遍历的路径被拒绝。
- 全局搜索、首页/游戏库/硬件导航沿用同一公共外壳；硬件快捷入口现在打开独立页面。
- 1487/1280/900/800/390宽度未发现页面横向溢出；窄屏单列摘要、操作栏重排、表格局部滚动。
- 图片和四个Canvas加载正常；浏览器控制台无错误/警告。

动态效果复用useGSAP/scope/生命周期清理/减少动态效果支持。图表不通过定时器或随机数制造实时读数，保持明确演示状态；真实硬件采集服务未接入。
