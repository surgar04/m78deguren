## 交互及可访问性

在 Codex 内置浏览器中实际验证：

- 中文、英文别名、大小写与全角字符搜索。
- 收藏、取消收藏、收藏筛选及刷新后保留。
- 空状态与无匹配状态。
- 添加游戏的空值、重复名称校验及成功后进入当前列表。
- 新增记录同步进入全局搜索，刷新后清除会话记录。
- Ctrl+K 全局搜索、Escape 关闭及触发器焦点恢复。
- 演示密码复制，剪贴板实际得到集中数据中的口令。
- 增强开关的真实界面状态、持久化与明确的未接入服务提示。
- 配对弹窗明确说明未开启服务，不生成假二维码或假连接。
- 全部 11 张页面 img 成功加载；壁纸独立加载。
- 页面没有 JavaScript 错误或警告。

检查了 1487、1280、900、390 像素宽度；body 宽度均未超出视口。900 像素时状态面板移至游戏区下方，390 像素时导航移至底部。最终文字权重与语义调整后重新检查主要区域和窄屏溢出。

原生 dialog 提供焦点约束，React 卸载时恢复仍存在的触发器焦点。图标有语义标签的父控件，装饰图标隐藏于读屏。GSAP 和所有程序化滚动尊重减少动态效果偏好。
