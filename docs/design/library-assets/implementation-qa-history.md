## 已实测交互

- 全角ＣＳ２、别名搜索；状态、收藏与平台筛选取交集，空结果可重置。
- 收藏与取消收藏、即时计数、刷新保留；旧版空收藏不会被默认演示收藏覆盖。
- 最近时间、名称、来源排序；排序不修改共享查询数据。
- 网格/列表切换、刷新保留；窄屏卡片改为单列，避免封面和标题过度裁切。
- 添加空名称/重复名称校验；成功新增后首页、游戏库与全局搜索使用同一查询缓存；刷新后移除会话新增记录。
- Ctrl+K、Escape、触发器焦点恢复；原生dialog约束焦点。
- 游戏库/首页导航、首页查看全部、跨页硬件/优化辅助区导航。
- 扫描与启动入口如实说明服务未接入，不伪造扫描完成或启动成功。
- 页面全部图片加载成功；无嵌套按钮、按钮内块级标题等无效结构；控制台无错误/警告。
- 1487/1280/900/390 宽度未发现横向溢出；窄屏元信息已收敛，列表与网格均复核。

GSAP 仅动画 transform/opacity，使用 useGSAP、scope、清理和减少动态效果媒体查询；所有图标显式导入 Font Awesome。现有 CSP 和原生最小权限边界未放宽。
