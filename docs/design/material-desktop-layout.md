# 桌面栅格与间距规范

本轮采用 Material 的自适应布局思路，具体尺寸为臻境产品取值，不表示 Google 的强制标准。
字体、壁纸、薄荷色、玻璃模式以及用户的导航偏好继续生效。

## 公共实现

- `src/styles/layout-tokens.css`：4/8/12/16/24/32/48px 间距、文字、圆角、导航和控件尺寸。
- `src/features/home/desktop-density.css`：公共外壳、内容分区和容器断点。替换原有密度覆盖，避免再叠加另一套桌面布局文件。
- `src/components/PageHeader.tsx`：标题、说明、状态标记、操作和页签插槽。普通页面不再重复首页日期。
- `WorkspaceLayout` 的 `data-layout` 标记限定适用范围，独立 HUD、歌词、屏幕测试窗口不受影响；`data-page` 仅表达页面类型，不保存业务状态。

## 尺寸与对齐

| 项目                       | 标准值                       |
| -------------------------- | ---------------------------- |
| 侧边导航宽度 / 窗口外留白  | 80 / 16px                    |
| 内容右边距 / 列间距        | 24 / 24px                    |
| 窄窗口边距 / 列间距        | 16 / 16px                    |
| 卡片内边距                 | 标准 24px，紧凑或窄窗口 16px |
| 模块 / 分组距离            | 24 / 32px                    |
| 页面标题 / 行高            | 28 / 36px                    |
| 分组标题 / 行高            | 20 / 28px                    |
| 正文 / 行高                | 14 / 22px                    |
| 次要文字 / 行高            | 12 / 18px                    |
| 独立按钮基准               | 高度或点击区域至少 40px      |
| 控件 / 卡片 / 大工作台圆角 | 12 / 16 / 24px               |

所有尺寸使用 CSS 逻辑像素，不使用 zoom 或 transform 缩放整页。紧凑偏好仅收紧留白。
内容工作区不锁死最大宽度，最大化后继续使用可用空间；设置正文限制在 880px 内。

## 页面规则

- 首页：12 列中的 4 列摘要与 8 列启动区；无侧栏时启动区占满。快捷启动列表自然增长，避免与页面形成双重滚动。
- 工具、优化和其他游戏目录：每项至少 280px，按容器宽度自然换列。卡片以最小高度排版，长名称和说明完整换行，收藏独立点击。
- 硬件：上部三项各占 4 列，下方趋势占 8 列、设备占 4 列。工作区不足 888px 后重排；600–888px 摘要采用两列，进一步缩窄后单列。
- Steam：封面保留比例，网格按容器换列；列表模式仍保持单列。
- 设置：宽工作区为 200px 分类栏和弹性正文；窄工作区分类换为可换行的横向页签。主页面统一滚动，分类切换回顶；四方向键、Home、End 可用，ARIA 方向跟随实际排版。
- 音乐：页头、提示、曲库和播放条按真实高度分配空间。窄工作区默认收起当前播放详情，并提供展开入口；矮窗口允许页面滚动，播放条不覆盖工作台。
- 导航：短窗口只滚动导航内部；顶部导航沿用同一边距，保持全部入口可到达。

正文卡片使用随主题变化的稳定表面，降低复杂壁纸对阅读的影响；导航与全局栏继续遵循玻璃偏好。
焦点使用主题对应的清晰描边，减少动态效果时关闭装饰过渡。

## 验证方法与边界

先运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 exec vite`，再在另一终端运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 test:layout:web
```

检查 8 个主页面在 760×560、1200×800、1440×900、1920×1080 下的横向溢出、播放区遮挡、键盘页签切换，以及侧边/顶部导航、浅色/深色、紧凑偏好组合。报告和截图位于 `.cache/verification/material-layout/`。
浏览器默认只读使用已有 Edge；需要其他浏览器时可通过当前进程的 `ZHENJING_LAYOUT_BROWSER` 指定现有可执行文件，不安装浏览器或修改全局配置。

工具长文本为独立浏览器中的测试夹具，优化分类来自仓库的产品白名单；没有原生后端的页面明确展示不可用状态。
这套检查验证布局与前端交互，不代表真实账号切换、系统优化、驱动安装、原生监控、Windows DPI 或发布版安装验收。Windows 125%/150% 显示缩放仍需在对应实际环境复核。
