# 工具页面设计简报

日期：2026-10-24（Asia/Shanghai）。本阶段提供设计图，不修改应用代码。

## 目标与视觉继承

帮助玩家快速找到、收藏并打开合适的工具。严格沿用已选首页和硬件页的浅蓝幻想壁纸、白色磨砂玻璃、薄荷绿强调色、MiSans中文层级、Font Awesome图标、左侧浮动导航和公共窗口栏。仅工具导航项选中。目标画幅1487×1058，不拉伸生成原件。

## 内容范围

依据本地《NexBox-功能全景与实现分析》整理：下载加速、网络测速、辅助准心、屏幕测试、时间同步、已有录屏管理、运行库修复及蓝屏日志。外部工具库单独标为第三方；不把第三方软件的能力写成本项目原生功能。优化设置继续由既有优化导航承载。

设计核心是工具发现与打开：搜索、分类、收藏和工具详情。维护与修复只呈现查看入口，不提供首页直接执行的批量修复/清理动作；录屏管理不写成屏幕录制。无虚构检测、安装、网络测速或性能提升结果。若预览下载保存位置，仅使用D盘。

## 三种结构方向

- 轻盈工具台：常用启动网格与收藏、外部工具入口。
- 聚焦工作台：分类、结果列表、选中工具预览。
- 分区工具架：按游戏辅助、网络下载、系统维护组织横向分区。

三者改变信息组织，不改变品牌、配色、壁纸或窗口外壳。最终编号以聊天中实际显示顺序为准。用户选图后再实施。

## 存储与授权
