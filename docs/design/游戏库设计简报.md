# 游戏库页面设计简报

日期：2026-10-24（Asia/Shanghai）。本阶段只生成设计图，不修改页面代码。

## 目标与视觉基准

让玩家快速找到、筛选并启动已有游戏，同时提供添加本地游戏、扫描与来源管理入口。沿用已选首页设计及当前实现：浅蓝幻想壁纸、薄荷绿主色、白色磨砂玻璃、深色中文文字、浮动导航、顶部搜索和自定义窗口栏。

参考图为 `homepage-assets/reference-selected.png` 和 `首页实现预览.png`，两张实际图片均附加到每次生成请求。延续相同的品牌、字体层级、图标语言和圆角；游戏库导航项选中。画幅要求为 1487 × 1058，实际生成尺寸单独记录，不拉伸图片。

## 页面内容

- 页头：游戏库、简短副文案；添加游戏为主操作，扫描本机为次操作。
- 工具栏：库内搜索、全部/已安装/收藏筛选、平台筛选、最近游玩排序及视图切换。
- 六款示例游戏与首页一致：三角洲行动、Counter-Strike 2、原神、崩坏：星穹铁道、鸣潮、星露谷物语。
- 卡片：封面、名称、收藏状态、平台与轻量安装/最近游玩信息。悬停或选中时呈现启动操作。
- 不复用首页硬件、增强开关与公告区，保持游戏浏览的内容优先级。
- 游戏状态、时间和数量均为设计示例，不代表扫描本机或已接入启动器。

## 同风格布局探索

- 全景书架：三列两行宽封面，完整展示六款游戏，适合快速浏览。
- 游玩工作台：紧凑游戏网格与右侧选中详情联动，突出启动和目录操作。
- 平台藏馆：Steam 与本地游戏分组陈列，在同一套外壳中突出来源管理。
