# 系统与硬件页面设计简报

日期：2026-10-24（Asia/Shanghai）。本阶段只提供设计图，不修改应用代码。

## 目标

帮助玩家理解设备配置与当前负载，通过适度的趋势和传感器详情定位异常。延续首页与游戏库的浅蓝幻想壁纸、薄荷强调色、磨砂玻璃、MiSans中文层级、Font Awesome图标、悬浮导航和窗口栏。硬件导航项选中，画幅要求1487×1058。

每次生成均附加已选首页原图及当前游戏库实现图。内容区保留足够不透明度，不另起深色监控台风格，也不复用首页的游戏封面、公告或增强开关。

## 功能取舍

- 核心：CPU/GPU/内存摘要、系统配置、磁盘空间、近期负载趋势。
- 扩展通过入口提供：设备详情、传感器、历史报告与导出；不将分析文档的全部功能平铺成卡片。
- 没有游戏运行时FPS显示未检测到游戏；指标不可用显示短横线，不用0假装采集成功。
- 三张布局方向分别为总览、选中设备详情、时间序列监测；共同采用同一套主题与设备示例。

## 统一示例数据

所有读数均为设计示例，页面明确显示“演示数据”，不代表本机检测结果或功能已经接入。

- CPU：AMD Ryzen 7 7800X3D，8核心16线程，18%、48°C、4.2GHz、35W。
- GPU：NVIDIA GeForce RTX 4070 SUPER，12%、42°C、显存1.2/12GB。
- 内存：16GB DDR5，使用7.6GB，即47.5%，6000MT/s；与首页7.6/16GB口径相同。
- 主板：MSI B650M MORTAR WIFI。
- 磁盘：D盘游戏SSD，1TB，已用438GB、剩余562GB。不设计C盘清理动作。
- 系统：Windows11专业版，64位。网络示例：下载2.4MB/s、上传120KB/s。
- 图表：最近60秒，截至现在；若出现日期，锚定2026年10月24日星期六。
