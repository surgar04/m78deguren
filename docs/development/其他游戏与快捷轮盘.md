# 其他游戏与桌面轮盘

## 识别覆盖

客户端定位使用安装记录、HoYoPlay 按 game_biz 保存的路径、启动器安装路径配置、桌面和开始菜单快捷方式、运行进程、Steam/Epic 安装清单，以及按需固定磁盘搜索。用户可以指定任意本地普通搜索目录。图标从实际登记的 EXE 资源提取；缓存放应用数据目录。

| 游戏             | 本体候选                                        | 区服依据                                                             |
| ---------------- | ----------------------------------------------- | -------------------------------------------------------------------- |
| 原神             | YuanShen.exe / GenshinImpact.exe                | 专用 EXE、HoYoPlay 游戏记录                                          |
| 崩坏3            | BH3.exe                                         | HoYoPlay bh3_cn / bh3_global、本安装 game_biz                        |
| 崩坏：星穹铁道   | StarRail.exe                                    | HoYoPlay hkrpg_cn / hkrpg_global、本安装 game_biz                    |
| 明日方舟         | Arknights.exe                                   | 本体 Unity app.info、Yostar tag、鹰角安装配置                        |
| 明日方舟：终末地 | Endfield.exe                                    | 鹰角安装配置 region（包括 AES-CBC 格式）、GRYPHLINK、官方 Steam 清单 |
| 三角洲行动       | DeltaForceClient-Win64-Shipping.exe             | 官方启动器的服务域名、Steam 清单                                     |
| 异环             | HTGame.exe / NTEGame.exe / NTEGlobalGame.exe    | 当前安装的 NTELauncher / NTEGlobalLauncher、Steam 清单               |
| 鸣潮             | Wuthering Waves.exe / Client-Win64-Shipping.exe | KRLauncher 安装路径、渠道配置、官方资源域名、Steam 清单              |

路径位置由本机配置决定，不能假定盘符、用户名或固定安装目录。Unity 候选要求对应的 `_Data` 和 `UnityPlayer.dll`；Unreal 候选要求对应客户端目录结构，不能只凭同名 EXE 宣称安装成功。鸣潮优先归并到根包装器，避免 Shipping 与包装器产生重复卡片。

共用文件名不构成区服证明。证据不足时显示“区服待确认”，允许针对当前安装实例修正；不会根据界面语言或任意中文目录名猜测国服。父启动器可以同时管理不同区服，不能混合其全局 JSON 的 game_biz 判断当前安装。

崩坏3还读取旧客户端的 `bh3_os`、`bh3_overseas`、`bh3_jp`、`bh3_kr`、`bh3_asia` 和 `bh3_tw` 标识；日、韩、繁中单独标记，东南亚归入国际服。扫描助手自身的临时用户目录保持隔离，玩家目录则从当前 Windows 身份与只读用户目录记录解析，避免把助手的空档案误当成玩家安装位置。

快速搜索和深度搜索都有时间、深度、队列、结果数上限，可取消，跳过目录联接、系统目录和大型资源目录。达到限额、断开磁盘或权限不足时不能声称穷尽全部位置；应指定更接近安装目录的位置重试。未找到也不能证明游戏没有安装。

## 启动和统一记录

检测结果按真实路径复用首页快捷启动 UUID。其他游戏、首页、导航和轮盘共用同一记录，不复制执行命令。Steam 实例交给真实 Steam 客户端启动；需要官方登录、更新或反作弊初始化的客户端优先走其启动器，不伪造登录参数或绕过反作弊。Windows 管理员清单需要提权时交给正常 UAC，开发验收不执行此分支。

仅从首页移除快捷方式不会视为卸载游戏。库内启动会核对并修复快捷记录关联，再调用同一启动服务；旧导航绑定不会自动改为其他目标。

## 导航与轮盘

设置 → 快捷键中配置八个导航位置及八个轮盘方向。目标包括首页登记的游戏/程序、已安装 Steam 游戏、原生快捷功能及工具页面。目标仅保存枚举和 ID，不接受脚本、命令行或 URL。

默认关闭轮盘；启用后关闭主窗口会保留托盘后台，退出托盘后停止。总热键关闭和快捷键录制期间释放轮盘。默认仅在 Windows 桌面响应长按 Tab；短按向原前台窗口重放正常 Tab，修饰键组合透传。滑动后松开 Tab 执行，中心、圆外、焦点变化或 Esc 取消。未移动鼠标时不执行，避免屏幕边缘位置误选。

渲染复用原生助手消息线程及键盘钩子，采用分层窗口，不增加常驻 WebView。图标在配置变化时载入；打开动画结束后仅在方向变化时重绘。键盘回调不执行文件扫描、绘制或 IPC。支持 DPI、多显示器工作区、大小、透明度、鼠标位置/屏幕中央及桌面范围设置。

## 验收边界

本机真实扫描未发现这八款客户端，因此不能据此宣称已逐款完成真实登录、更新、反作弊初始化和游戏启动测试。八类目录布局、共享文件名不猜区服、重复路径归并、取消、鹰角加密国服/国际服配置采用独立测试目录验证，不进入应用档案。桌面联调使用实际 Rust IPC，验证真实扫描、八槽位保存和导航、窄窗口、原生预览、轮盘钩子开关、收托盘后存活及总热键开关；不执行游戏启动、驱动或系统修改。

轮盘默认关闭。在设置 → 快捷键中启用并保存；主窗口可以关闭，托盘后台必须保持运行。从托盘彻底退出后，轮盘不再响应。需要系统修改确认的工具只能打开对应页面，不会因绑定到导航或轮盘而获得额外权限。
