# 内置工具重构与验收

## 实际能力边界

- 不把缺少传感器、旧驱动不支持或权限不足的数据填成正常值。当前显卡为 GeForce 210；此硬件不能验证 RTX DLSS 效果，相关失败须明确展示。
- 显示器 Gamma 是每通道曲线；真正饱和度使用 Windows 全桌面颜色矩阵，作用于所有显示器，界面明确告知。ICC 工具处理 VCGT/TRC 校准曲线，不能宣称实现完整色彩管理或系统 ICC 配置安装。HDR/驱动接管时可能拒绝校准。
- 性能叠加的未提供传感器保持空值；PresentMon 需要当前系统支持与用户明确授权，低帧指标需要足够有效样本。EQ 响应图是处理器频响，不伪装实时 FFT 频谱。系统声音需由用户选择 FxSound 虚拟播放设备，再在本工具选择物理输出，避免自动改变默认设备和产生回授。
- 虚拟化工具管理 Windows VBS/HVCI/BCD，不能从普通 Windows 应用替代 BIOS 的 VT-x 开关。隐藏功能属于当前 Windows 版本的实验配置，保留接口错误。
- VAC 不能解除账号封禁。恢复入口撤销本次服务、防火墙和启动配置；Valve 安装器及程序运行会话不能撤销。软件卸载、存储整理和已完成的设备重启也不能伪造“撤销”，界面明确说明适用恢复方式。
- 应用管理枚举 Win32 卸载注册项，不能把它称为全量 UWP 包管理。蓝屏工具不执行符号加载或调用栈根因归责。高校测速节点可能限制外网；上传来源在界面明确展示。

## 安全与工程实现

所有源码、安装包、临时文件、日志、持久化偏好、脚本及 WebView 数据位于 D 盘。C 盘现有组件只读使用。用户授权的系统变更例外只在应用运行时逐项确认后适用；开发验收不自动执行系统安装、配置修改、点击注入、颜色修改或音频捕获。

原生 IPC 只接受严格领域枚举和不透明 ID，前后端都验证输入。辅助窗口按角色限制调用。服务状态只在 TanStack Query，组件仅保留尚未提交的草稿。运行时没有工具模拟数据；固定产品目录、图案、频率与协议常量不是设备读数。

系统修改协议为预览、状态指纹、120 秒一次性确认、串行执行、D 盘备份和回执。脚本及请求在执行期间持有拒绝写入/删除共享的句柄。恢复先校验整批当前值，避免覆盖后续修改；失败时逆序恢复；恢复动作失败时也回滚已恢复的条目。不可自动恢复的情况保留明确错误与备份。

HTTP 复用受限客户端，有连接/读取/操作超时，过滤内网 DNS、危险重定向及大响应。音频实时回调不执行文件或网络 I/O，使用环形缓冲、参数原子切换与有界 DSP。

## 桌面尺寸与功能卡图标

主窗口默认逻辑尺寸调整为 1200 × 800，启动时按显示器 DPI 和工作区进一步收敛，避免遮挡任务栏。布局通过字号、间距和网格调整实际密度；不对整页使用缩放。六个页面共享桌面密度规则，较窄窗口允许自然滚动。

工具与优化分类卡共用 `FeatureIcon`。图标容器为 48 像素，图形约 23 像素；采用低饱和语义色、细边框与统一留白。卡片摘要限制为两行，完整说明保留在标题提示和详情页。

2026-10-25 的布局验收覆盖首页、游戏库、硬件、工具、优化及设置，在 1200 × 800 和 1024 × 720 共生成 12 张截图，检查横向溢出、图标尺寸、最近游戏图片边界与后续内容间距。证据目录为 `.cache/verification/desktop-density/`。

## 验收命令

- `dev.ps1 check`：格式、ESLint、严格类型、前端测试、Rust 格式/Clippy/测试。
- `scripts/verify-builtin-readonly.ps1`：固定只读 Windows 查询；证据在 `.cache/verification/builtin-readonly/`。
- `scripts/verify-system-transactions.ps1`：使用内存写入适配器验证七项事务路径；实际系统写入为零。
- `dev.ps1 desktop:test:dev` 和 `dev.ps1 test:tools:desktop`：独立 D 盘测试数据，23 个工具页面与外部入口、真实 IPC、视频缩略图、透明窗口、全屏测试、实际测速、辅助窗口权限。
- `dev.ps1 desktop:bundle`：必须实际链接 Windows EXE 后打包。PresentMon 的 MIT 许可证随 ZIP 分发。

本文件的功能表描述代码覆盖范围；验收结果以对应结果 JSON、命令退出码和最终产物为准。未在本机执行的系统修改不能记为实机通过；远程 CI 尚未运行。
