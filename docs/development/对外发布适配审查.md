# 臻境 0.5.1 对外发布适配审查

本次范围是移除开发机环境假设，保留真实数据、输入验证、逐项确认、备份和恢复。开发工作区仍是 D:\新境，验收不向 C 盘创建文件，不执行安装器、账号切换或系统修改。

## 数据与兼容性

- 默认安装目录：%LOCALAPPDATA%\Programs\Zhenjing；默认数据：%LOCALAPPDATA%\Zhenjing。两者分离，用户之间不共享 Steam 记录、快捷启动、备份和浏览器档案。
- --data-dir、ZHENJING_DATA_DIR 和兼容变量 XINJING_DATA_DIR 优先于默认目录。此前手动运行旧版的用户，可用显式路径继续使用旧档案；不悄悄迁移或删除数据。
- 旧版 localStorage、壁纸 IndexedDB、维护锁、启动项技术标识及签名更新兼容代码仍保留。
- 开发脚本设置进程变量 ZHENJING_RESTRICT_WRITES_TO_D=1，路径策略仍拒绝本机其他磁盘写入。该变量不内嵌为产品默认设置，也不修改系统环境。
- 高风险操作、安装、账号删除仍遵守界面确认；此改动没有自动执行系统修改。
- 录屏暂存不是缓存，清缓存或卸载不会主动删除视频暂存文件。
- 数据根在启动及真实路径规范化后复核：拒绝 Windows、Program Files、ProgramData 子树、整个用户/缓存根和程序安装根，避免后续数据重置误操作。安装器同时拒绝将程序装入默认数据根；应选择与档案分开的独立安装目录。

## 运行依赖

- 主程序原生编译；用户不需要源码、开发工具链、Node 服务或 Vite。
- 硬件助手 SelfContained=true、PublishSingleFile=true，运行时从主程序内嵌资源提取并校验，.NET 解压目录明确放在用户数据范围内。
- Windows 自带 PowerShell、WMI、WinRT 及 WebView2 承担各自能力。设备、驱动、权限或组件不支持时返回真实不可用状态。
- 安装包当前不附带 Windows Authenticode 证书。更新清单的 Ed25519 签名与 Windows 代码签名是两套机制，不能混称。

## 验证边界

路径测试覆盖 C/D/E 盘、不同用户名、中文与空格、UNC、设备路径、相对路径、ADS、目录穿越、开发限制；C/E 盘用只读或纯语法测试，不在这些盘创建夹具。

原生环境测试抽取真实维护函数，用内存进程适配器检查重启环境，不启动安装器或执行系统操作。录屏和下载生命周期测试均使用 D 盘隔离夹具。

发行验收使用实际 Release EXE，复制到独立的中文/空格目录，移除开发路径与显式数据变量，以新的模拟用户环境启动，检查默认目录、内嵌助手和真实日志。该验收不能代替另一台干净 Windows 电脑上的安装/卸载、权限和实际升级验收；远程 CI 未运行时不得声称已通过。

已通过的代码与原生验收：前端 22 文件、76 项测试；Rust 70 项测试（6 项环境测试跳过）；安装引导 8 项测试；TypeScript、ESLint、Rust Clippy；真实 C# 路径验证、图标提取及退出看门狗；设置只读状态和显示器探测。证据位于项目 .cache/verification/distribution-*，不随安装包分发。

实际 Release 已成功链接；NSIS 安装包完整性、包内 EXE 一致性（只允许 Tauri 安装类型标记的三个字节差异）、四项二进制直接依赖及更新清单签名均校验通过。搬迁启动已通过：独立中文/空格目录、全新模拟用户目录、无显式数据路径、无开发 PATH/SDK 环境变量，内嵌硬件助手正常运行并持续记录真实硬件历史。首次启动尚未修改偏好时不会生成配置文件，这是正常的惰性持久化行为。
