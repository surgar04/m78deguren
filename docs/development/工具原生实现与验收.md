## 代码分层

- `src/lib/desktop.ts` 是唯一前端原生入口；`tool-contracts.ts` 在输入和返回边界执行 Zod 验证。
- `src/features/tools/native/` 按工具拆分界面；TanStack Query 只缓存服务快照，未提交表单留在组件，收藏/最近访问沿用 Zustand 偏好。
- `src-tauri/src/commands/tools.rs` 使用带标签、拒绝未知字段的请求枚举；按调用窗口检查权限。
- `services/tools/` 分离下载、录屏、准心/屏幕、网络、运行库、目录和 Windows 桥接；共享有超时的 HTTP 连接池。
- `windows.ps1` 是固定脚本。Rust 传结构化参数，不能传入脚本代码或任意命令；脚本按内容哈希写入 D 盘并带 UTF-8 BOM，兼容 Windows PowerShell 5.1。
- CPU 密集解码、同步文件和原生目录选择放入阻塞池；网络及后台任务使用 Tokio 和取消令牌，不依赖页面挂载存活。

## 存储与访问约束

默认根目录为 `D:/新境/.local/data/tools/`；独立测试根目录在 `.cache/verification/`。下载任务、分段、限速设置、准心配置、恢复清单、安装回执、脚本、子进程临时目录和辅助 WebView 配置都在 D 盘。

目录验证拒绝 C 盘、相对路径、父目录穿越、符号链接及 Windows 目录联接点。录屏通过原生选择器加入允许列表，前端使用不透明摘要 ID。媒体协议只读取扫描得到的 ID，单响应最多 16 MiB，同时最多四个读取任务；CSP 只增加该媒体协议来源。

下载禁用隐式系统代理，DNS 解析过滤本机/内网/保留地址，逐跳验证重定向且禁止 HTTPS 降级 HTTP。文件名拒绝 Windows 保留名及特殊字符；成品以排他硬链接发布，不覆盖同名文件。当前要求下载目标文件系统支持硬链接，例如 NTFS；不支持时明确失败并保留原文件及缓存，不能假报完成。

安装器只允许运行库白名单生成的路径，不暴露通用 Shell。普通下载的可执行文件只能定位或另存；无法从下载面板直接执行。运行库的确认凭据十五分钟有效、一次使用。若安装器状态未知，明确要求核实，防止重复启动安装器。

## 验收方法

常规检查：`powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 check`。

真实联网与 Windows 只读探测：加载 `scripts/env.ps1` 后运行 `cargo test --manifest-path src-tauri/Cargo.toml --locked live_windows_and_official_sources -- --ignored --nocapture`。该测试保存官方安装包链接、系统组件、事件、显示设备与六个 NTP 节点的实际结果，不执行校时或安装。

原生 WebView 验收：通过 `desktop:test:dev` 启动独立 D 盘数据目录，再在同样的 D 盘环境中运行 `node scripts/smoke-tools.ts`。证据在 `.cache/verification/tools-desktop/`，包含九个真实入口、原生查询、准心窗口、全屏绘制和退出、测速停止、脚本/CSP 错误检查。

Rust 文件测试直接在 D 盘创建文件及本地 HTTP 服务，验证分段覆盖、跨会话恢复、Range 回退、哈希拒绝、受限路径、复制不覆盖、重命名/恢复及媒体 Range。常规测试不依赖公网。只有标记 `ignored` 的显式测试访问公网。
