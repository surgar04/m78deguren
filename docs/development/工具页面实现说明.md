# 工具页面实现说明

> 本文保留初版 8 项工具与设计基准的历史记录。当前 23 项内置工具、桌面密度调整、实机验收和发布产物请见[内置工具全量重构验收](./内置工具全量重构验收.md)。

## 视觉目标与结构

独立路由`/#/tools`，本轮用户附件是唯一视觉目标，保存为`docs/design/tools-assets/reference-selected.png`。基准1487×1058；复用首页壁纸、MiSans、磨砂玻璃、窗口栏、导航及GSAP生命周期，不用整页截图代替界面。

页面包含搜索、全部/收藏/最近使用筛选、收藏管理、游戏辅助和网络下载两排卡片，以及共享玻璃面中的系统维护/外部工具入口。工具卡的打开与星标是独立按钮；第三方入口不计入8项内置工具数量。1280/900/800/390宽度采用网格重排，文字不省略。

## 初版原生实现（历史记录）

本页已经完成从设计演示目录到 Rust 服务的迁移。原 `TOOLS_DEMO` 已从生产数据模块删除；普通网页明确提示使用桌面应用。工具页使用本机日期、真实工具目录及各工具的实际服务快照，不提供伪造执行结果。

完整功能矩阵、模块职责、磁盘与权限约束、运行库逐项安装例外、验证方法与证据见 [工具原生实现与验收](工具原生实现与验收.md)。

搜索、收藏、最近访问的产品行为继续保留：收藏和最近仅持久化 ID；最近访问不等于执行成功；关键词支持全角、大小写、空格归一化及多关键词交集。原生 dialog 提供焦点约束和 Escape 关闭，关闭后恢复触发器焦点。
