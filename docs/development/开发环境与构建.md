# 开发环境与构建

入口为根目录 `dev.ps1`，先加载 `scripts/env.ps1`。开发机全部新建数据写入 D 盘；现有 C 盘工具只读复用。不要修改全局 PATH、用户 npm / Cargo 配置或执行全局安装器。

1. 将工程放在 D 盘。本机工作区为 `D:\新境`。
2. 阅读 `scripts/bootstrap.ps1` 参数，在 D 盘恢复便携 Node、pnpm、Rust、MSVC 与 Windows SDK。MSVC / SDK 来源必须是已有合法可用组件，不能借本入口静默安装系统软件。
3. 通过 `scripts/prepare-dotnet.ps1` 准备 D 盘便携 .NET SDK。
4. 运行 `dev.ps1 env:check`，通过后按锁文件安装依赖，再运行 `dev.ps1 music:prepare`。
5. 运行 `dev.ps1 desktop:dev` 启动桌面，或 `dev.ps1 check` 检查质量。

Tauri 前端生产资源输出到 `.cache/frontend`，与 `dist/desktop` 和 `dist/desktop-developer` 的已签安装包分离。原生 DLL 使用来源及逐文件摘要清单，修改对应源码后须重新构建组件，不能只改哈希来跳过检查。

正式应用不依赖本地工具链。具体安装布局见 [安装组件与 DLL 布局](安装组件与DLL布局.md)，发行步骤见 [MSI 发布与签名](MSI发布与签名.md)。开发者版见 [开发者版本与认证](开发者版本与认证.md)。
