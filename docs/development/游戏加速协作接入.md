# 游戏加速：QuickFox 官方客户端协作

工具地址：`/tools/game-acceleration`。设置 → 网络也有入口。其他游戏中已检测、可用且标记为国服的实例显示“国服加速准备”。普通游戏启动默认保持直接启动；国内玩家无需配置加速器。

## 操作流程

1. 用户在官网安装 Windows 客户端；臻境检测 HKCU/HKLM 的 32/64 位安装记录、标准目录及正在运行的客户端，也支持原生选择器手动定位。
2. 选择检测出的安装实例。服务验证本地 EXE、有效 Authenticode 证书链、发布组织、产品信息与 SHA256；不接受安装器、任意网址或前端提供的命令行。
3. 选择已检测的国服游戏并开始本次准备。需要时打开 QuickFox；登录、游戏模式、连接与购买完全在官方客户端完成。
4. 用户明确勾选已在官方客户端开启游戏加速，再确认本次启动。这是业务前置条件，不能被全局“减少二次确认”跳过。
5. Rust 重新检查客户端身份、进程 PID/创建时间、游戏 ID/实际路径和区服，再复用游戏库启动链路。一次会话只能提交一次启动请求。
6. 游戏退出后按偏好在臻境内提示用户回到 QuickFox 按需断开。不结束第三方服务，不自动断开，不恢复或重置全机网络。

## 明确的状态边界

- “客户端已运行”仅依据已登记的完整镜像路径，不依据进程名称。
- “本次已确认”来自当前一次操作，不是加速结果。客户端退出/重启后失效，等待确认最长十分钟；打开客户端超过四十秒仍未发现进程则失败。
- 游戏状态只依据登记的客户端完整路径；启动器登录/更新期间显示“启动请求已提交”，不会假装游戏已经运行。十分钟未出现游戏时失败。
- “游戏结束”需要连续三次读数未发现该游戏，降低瞬间重启的误报。“停止跟踪”不会关闭任何软件。
- 当前没有核实到公开 Windows 加速控制 API，因此没有私有接口调用、自动点击、密码保存、虚构 Ping 或“加速生效”状态。
- 三位朋友的账号和会员由官方条款决定；多设备权益不作为允许朋友共用账号的依据。先试用并在马来西亚三人同时游玩时观察实际延迟、抖动、丢包，再决定购买。

## 数据、资源与验收

- 只持久化应用数据目录下 `acceleration/config.json` 的客户端身份与退出提醒偏好；会话不持久化，重启后不继承确认。
- 客户端更新导致摘要变化时须重新检测选择；没有证书链/无法识别的版本明确失败，不能降级为按名称信任。
- 只在活动会话中每两秒读取进程路径与创建时间；没有活动会话时无后台任务。页面可见时低频读取状态，不重复采集硬件、带宽或进行公网探测。
- Rust 使用 sysinfo 的 system 最小特性，关闭磁盘、网络、传感器等默认特性；不携带 QuickFox 安装包，不加入隧道、驱动或节点引擎。
- 开发机 D 盘保护开启时不启动会自行写入系统盘的第三方客户端；可执行只读检测、IPC/状态机测试和 UI 验收。日常发布版正常由用户主动打开客户端。
- 官方 Windows 安装器只用于只读核验，2026-10-30 核验签名组织为厦门科臻赛科技有限公司，官网来源 `https://cdns3.quickfox.com.cn/51/QuickFox.exe`，当次 SHA256 为 `38d574915676763a1ba0ab63b089eb3ff4192c1a012f5335ef5b61ff58ce5b3c`。这不是固定版本下载依赖，厂商更新不要求旧安装器摘要一致。
- 另以只读解包核验安装器中的 QuickFox 3.59.6.0 客户端，非执行安装。实际客户端签名有效且组织相同，产品名与说明均为 QuickFox，SHA256 为 `9a2f5ae9d288c7868b395357d7232c8db809c3b345296d9a97824c8be19cdec5`，通过本项目原生身份验证脚本。临时安装器、内部压缩包和解包客户端均已删除，仅保留忽略目录中的 JSON 核验回执。
- 本机无官方客户端及目标游戏时，不能将单元测试或安装器签名核验描述成真实加速验收；真实登录、连接、启动与断开仍须在安装了官方客户端和游戏的海外电脑验收。
