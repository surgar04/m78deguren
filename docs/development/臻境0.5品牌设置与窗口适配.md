# 臻境 0.5：品牌、确认策略、窗口与更新

## 变更

- 应用显示名称统一为“臻境”，英文名及构建名称使用 Zhenjing / zhenjing。窗口、托盘、默认 Logo、关于页、安装包、硬件助手和报告同步更新，默认 Logo 使用本地 SVG。
- 首页不再展示项目交流入口，通用设置中也移除该卡片开关。使用指南内置，问题反馈仍连接指定仓库的 Issues。
- 原生配置新增 `confirmActions`，默认开启；旧配置缺少该字段时同样为开启。关闭后，游戏模式、自动游戏模式、游戏 Win 键策略及进程恢复可由明确点击直接请求原生服务。移除账号、安装更新、驱动、运行库及高风险系统操作仍保留独立确认。
- 公共内容区移除 1420/1480px 的固定宽度限制。窗口尺寸变化交给 CSS 网格和媒体查询；顶部/侧边导航切换也重新计算可用宽度，不缩放整页或缓存首次窗口尺寸。
- 更新检查、自动下载及提醒分开保存。自动检查默认开启，首屏启动后检查，正常每四小时复查，网络失败后适度重试。全局提醒支持稍后处理，下载就绪或签名补齐会重新提醒；跳转更新页时，即使已经停留在设置页也会切到“关于”。

## 数据兼容与存储

工作目录仍按工程约定保留为 `D:\新境`。开发数据仍使用项目的 `.local/data`；新安装优先采用 D 盘新品牌目录，已有默认档案原位读取。已知旧 localStorage 偏好复制到新键，已有新值不会被覆盖，原值不删除。IndexedDB 壁纸库、数据互斥锁及启动项的必要技术标识保留兼容读取，避免丢失已导入素材或留下两个开机启动项。

旧安装目录只有在安装标记符合已知身份时才允许接管。安装器备份旧 EXE，再写新程序和新快捷方式；无法备份或写入时停止并尝试恢复。迁移及安装只由用户实际运行安装包时执行，开发验收不写卸载注册表和快捷方式。

## 更新信任边界

发布源为 `surgar04/m78deguren`，新清单为 `zhenjing-update.json`。仅接受固定应用、Windows x64、稳定通道、仓库及版本路径，必须通过 Ed25519、SHA256 和长度校验。缺少清单时会读取 GitHub 最新 Release 元数据，区分“没有发布”和“存在发布但缺少可信清单”；后者可提醒并展示信息，不能直接下载或安装。

状态读取、检查和待更新指针变更串行处理，避免旧下载覆盖新版本状态。更新安装凭据有时效且单次使用。自动下载不等于自动安装，安装始终需要单独确认；界面的“查看发布页面”通过固定原生白名单打开仓库 Releases。

## 本机验收

- 前端 21 个文件、66 项测试通过，包括偏好迁移、确认开关和提醒去重。免确认触发仅使用隔离单测，不用真实开发机执行进程压制或 Win 键启用。
- Rust 65 项通过、6 项跳过；安装引导 3 项通过。类型检查、ESLint 与 Clippy 通过。
- 真实桌面验证 1200、1920、2560、760 四种宽度，均无横向溢出；实际原生窗口最大化/还原通过，最大化时右侧间距为 20px。
- 顶部/侧边导航切换、设置页内切换“关于”、确认偏好刷新持久化及默认确认弹窗通过。真实更新源当前返回没有可用签名发布，未使用假版本或假下载进度。
- 一次尝试替换 IPC 函数进行验收被框架只读保护阻止，已删除该测试方式。实际桌面只验证确认策略持久化和开启后的确认门槛，免确认点击改用隔离单测。结束时游戏模式和 Win 策略关闭，后台调整数及待恢复数均为 0。

验证截图与机器可读结果位于 `.cache/verification/zhenjing-desktop/`。安装包、真实跨版本安装及远程 CI 的最终状态以当次构建/验收日志为准，不能把单元测试当作已执行安装。
