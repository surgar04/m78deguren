## 功能与状态所有权

- 强调色：薄荷、晴空、薰衣草，原生单选框控制；作用于共享外壳的强调色令牌和选中状态。
- 柔化背景：复用 useHomePreferences.wallpaperDim，与顶部外观弹窗保持同一来源。
- 紧凑布局：复用 usePreferences.compact，缩小设置行和列表间距；通用分类不复制状态。
- 减少动态效果：系统偏好或始终减少。公共 useGSAP 使用 scope、matchMedia、revertOnUpdate 与清理；始终减少时跳过入场并关闭过渡，滚动同样尊重偏好。
- 分类：外观、通用、快捷键、数据与存储、关于均有可用内容。关于版本来自 package.json 或已有 app_info 查询，不虚构更新检测结果。
- 使用文档：本地原生 dialog，支持 Esc、焦点约束及关闭后返回触发器。
- 恢复默认外观：明确确认后恢复强调色、布局、动态效果、背景柔化及壁纸；不清空游戏/工具收藏和优化草稿。

Zustand 仅持久化有限用户偏好，保留原 v1 紧凑记录；Zod 对未知值、旧记录和损坏字段回退，不允许持久记录覆盖动作。TanStack Query 是设计素材及壁纸资源的唯一查询缓存。

## 本地壁纸

支持 PNG/JPEG/WebP，最大 8 MiB，至少 320 × 180，最多 2400 万像素。写入前检查类型、大小并实际 createImageBitmap 解码，始终关闭解码资源。失败在弹窗中显示，不替换原图。

二进制存于当前源固定 IndexedDB，不将大图片放进 localStorage，也不保存源文件路径。事务完成后才更新共享 Query，FileReader 生成的图片资源随 Query 共享，未扩展 CSP、原生文件/命令/网络权限。顶部外观弹窗和所有工作区使用同一份壁纸查询。

桌面数据沿用 Rust 指定的 D:\新境\.local\data，其 WebView 子目录承载 localStorage/IndexedDB。浏览器预览属于当前浏览器源，数据页明确区别这两种环境。本轮没有修改 Rust 或权限配置。
