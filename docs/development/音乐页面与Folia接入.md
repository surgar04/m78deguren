# 音乐页面与 Folia 接入

上游固定为 `chthollyphile/folia-major` 的提交 `42ff951c9106d0b59a7683ca6dceea019760b339`。前端渲染器、平台归一化、歌词解析和匹配算法的原件在 `integrations/folia-engine/upstream`，桌面平台桥在 `native/music-host/upstream`，摘要记录在 `integrations/folia-source.json`。不复制 Electron 主程序，也不将整套 Electron 运行时装入 MSI。

## 运行链路

- `/music` 使用臻境公共外壳；默认不打开沉浸画布。音频只有一个宿主实例，切换路由继续播放，系统媒体会话提供播放、暂停及切歌。
- 平台 API 经 `desktop.ts → music_execute → Rust 音乐服务 → 独立 Node 子进程`。媒体只暴露原生协议中的 UUID；子进程仅监听带随机口令的 IPv4 回环端口，口令不交给页面。
- 网易云复用上游完整 worker，包括 xeapi、匿名凭据、扫码身份和重试。QQ 使用无监听副作用的 serverless 入口。YouTube Music 复用上游平台桥；第四个来源入口为本地曲库。
- YouTube 播放器及 BotGuard 脚本在无应用能力、无外网的独立 WebView 中执行。会员、地区和曲目版权由平台决定，不提供绕过方式。
- 账户仓库使用当前 Windows 用户的 DPAPI；无加密能力时不写明文。数据随当前档案保存，开发机入口仍强制 D 盘。

## 本地音乐及匹配

原生文件选择器登记文件或目录；扫描只读原件，跳过链接及联接。索引、提取封面、导入歌词与匹配覆盖层放在用户档案的 `music` 子目录。移除歌曲只移除登记，恢复补全不改动原始标签。离线磁盘或被移动的文件不能阻止主程序启动。

支持读取真实音频标签和内嵌封面、相邻歌词，以及主动导入的同步歌词。在线匹配沿用上游标题、歌手、专辑及长度评分；由用户选择正确版本，不通过均分整句来伪造逐字时间。平台未给歌词、音源或版权不可用时显示实际空状态和错误。

本地曲库独立提供本地音乐与本地收藏，不发起账号请求；匹配弹窗可在上述三个在线平台间切换。旧版 Spotify 选择迁移到本地曲库，只移除其收藏引用并忽略其本地元信息覆盖层，保留其他偏好、平台会话、导入索引及原始音频。冻结的完整上游快照用于许可证和来源校验；构建时移除已撤下的提供者注册，生产目录只复制仍受支持链路的依赖闭包，禁止 Spotify 模块进入产物。

## 沉浸演绎与性能

17 种样式：流光、心象、云阶、浮名、群唱、倾诉、回环、莫奈、镜台、时计、商籁、凝彩、绘光、雾笺、花火、町景、静止。六种背景：通用、隐现、莫奈、漫游、空、嵌入网页。模式及背景的原始参数面板一起接入。

沉浸页是独立同源文档，用于隔离原项目的 Tailwind、字体和着色器样式。歌词及主题改变才发送状态，高频时钟和 FFT 通过 MessagePort / MotionValue 传递，不每帧刷新 React 曲库。退出移除整个文档并断开音频分析节点；普通播放器保留直连声音输出。支持帧率和分辨率控制，图形失败保留控制及退出入口。

默认与封面派生配色沿用上游主题算法，自定义主题保留字体、关键字色及图标字段。Noto Serif SC 字体在构建时改为固定版本本地资源；雾笺的 AnimCJK 笔顺与许可证必须完整生成，缺失时构建失败。

提供自动、原画、低开销三种图形策略。原画保留上游像素预算；自动仅在识别到软件显卡时使用通用背景和较低歌词采样，保留用户原先的动态背景选择。切换原画即恢复。软件渲染与硬件加速的测试结果分开记录，不能以降低画质后的结果声称原画在任意设备上流畅。

## 构建与验证

所有命令通过项目 `dev.ps1` 入口：

1. `music:build`：构建预编译 API 与演绎文档。
2. `music:host:build`：从同一 pnpm 锁文件创建无符号链接的生产组件，携带独立 Node 和三个在线平台所需依赖，逐文件生成摘要；不再包含 librespot 原生插件。
3. `node scripts/verify-music-host.ts`：在独立 D 盘目录验证子进程协议、媒体口令、端点和私有地址拒绝、真实 WAV 解析，以及未登录状态；不登录私人账号。
4. 前端测试验证 17 项注册表与上游一致，检查 IPC 与歌词契约。发布前仍需实际链接 Windows 主程序及真实桌面播放验收。

**边界：** 编译通过不代表三个在线平台的私人账号登录、会员曲目、区域可用性或全部硬件上的帧率通过。虚拟显示设备与不支持 WebGL 的机器不能作为 3D 效果的原画流畅性证明；这些结果须单独记录。

此前本机验收已实际链接 Windows EXE，并验证本地播放及歌词、网易云与 QQ 的真实搜索/封面/歌词、YouTube Music 搜索及 `206 audio/webm` 分段读取，以及本地元信息匹配、封面补全和还原；未代用户登录私人账号或验证会员曲目。平台移除回归另行验证三平台请求隔离、原生公共搜索/封面、本地元数据、YouTube 授权生命周期，以及生产目录不含已撤下的模块。

17 种模式已在同一桌面窗口连续切换，无 JavaScript 异常。另以软件渲染器分别检查全部模式，自动低开销策略约 59–60 FPS；该结果不代表原画策略在其他设备上的性能。无 WebGL 时可使用静止样式恢复。桌面验收还检查了 760、1200、1920 的 CSS 视口、顶部导航、原生全屏状态及退出后的画布释放。

全屏和音频分析由共享串行会话管理，合并 React StrictMode 双挂载或快速重进产生的过期操作。回归测试覆盖迟到的进入回调、快速退出和快速切歌。全量前端测试存在本机 fork worker 偶发启动超时；对应文件单独重跑通过，不能将这类运行记录描述成整套命令一次无错误通过。

## 封面与桌面歌词（2026-11-02）

普通播放器采用独立滚动的曲库主体；平台与账号、来源与搜索合并为两行工具栏，分页放入列表滚动区。播放与演绎参数从当前歌曲卡片移至专用弹窗，平台连接弹窗分为平台说明和授权操作两区。

QQ 封面优先请求同专辑的 800px、300px 版本，再回退原始资源；截图中的《浮舟》原图超出有界读取上限，缩略图正常。服务端只接受固定平台 CDN、验证图片魔数，采用 16 MiB/96 项 LRU、15 分钟有效期并合并并发请求。失败不缓存，前端保留占位图并重新获取一次详情；不会通过放开 CSP、读取任意网址或取消大小限制修复封面。

QQ 未登录搜索使用本机同源适配器的公开接口，保留上游归一化和 20 条页长，避免匿名直连周期性返回 2001。已登录用户仍采用原有会话搜索，账户错误不降级绕过。公开搜索仅对 5xx 做一次有限重试，同词重搜重置到第一页。平台扫码返回的长授权串封装为仅内存保存的短票据，界面及 Query 键只保存短 ID；最多保留 8 次尝试、10 分钟过期，关闭或淘汰时取消对应平台尝试。

桌面歌词入口位于音乐页标题操作区。独立透明、置顶窗口复用应用 WebView 数据目录，使用 AMLL 0.6.0 DOM 渲染核心，不开启其背景画布。支持拖动、边缘调整大小、字号、不透明度和锁定穿透；锁定后从音乐页设置解锁。位置延迟合并保存，屏幕拔除后恢复到有效工作区。正常播放按 4 Hz 发送时钟，歌曲/歌词变化时发送内容；暂停后移除定时器，只在跳转或状态改变时同步，并在接收端过滤重复读数。关闭销毁窗口并停表，沉浸会话暂停时钟并隐藏窗口，退出恢复。暂停及不可见时停止连续动画帧。

沉浸演绎的“隐藏操作栏”进入手动隐藏状态，鼠标移动不会唤回。按 `H` 恢复操作栏，`Esc` 保留退出能力。此状态只影响操作界面，不改动原始 17 种歌词渲染器。

封面回归命令：`node --test scripts/test-music-images.ts`；真实发布组件链路：`node scripts/verify-music-host.ts`。后者使用独立 D 盘数据目录，读取 QQ 与网易云公共封面，不登录私人账号。桌面歌词原生入口再次校验窗口身份、配置和歌词/时钟大小；辅助窗口只能读取歌词状态及关闭、锁定、拖动，不能访问账户、本地文件或平台管理接口。
