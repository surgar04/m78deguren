# MiSans 字体说明

本应用使用小米 MiSans 原始可变字体 `public/fonts/MiSansVF.ttf`，未改编或二次开发。字体版权归小米及其相关权利方所有，不属于本项目的原创代码。

- 字体来自本地参考仓库中保留的 MiSans 原始文件。
- SHA256：`0DDEF90648998900175CFDCA9A6F087A2544C182F130B0AD4F7E94A03A115E79`。
- [小米官方说明与许可](https://hyperos.mi.com/font/zh/download/)。
- [官方 FAQ](https://hyperos.mi.com/font/faq)：字体可在各平台及商业项目中使用。
- 官方许可 PDF 已保存在本目录 `MiSans许可协议.pdf`。

按照许可要求，在应用偏好设置的“关于新境”中注明字体使用。本项目保留完整字体，以支持用户自行添加的中文游戏名称；没有为了减小体积修改、子集化或重命名字体文件。
