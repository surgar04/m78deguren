# 设置与桌面生命周期

0.5.1 起，本文的 D 盘路径仅指本机开发环境。发布版默认使用当前用户 LOCALAPPDATA\Zhenjing，安装目录和实际磁盘不再写死；维护重启会保留原用户环境。最新策略见 [对外发布适配审查](development/对外发布适配审查.md)。

设置页使用真实 Rust IPC；没有设置演示数据源。UI 选择与原生状态分离：`features/settings/ui-store.ts` 保存主题、字体、背景、导航和首页可见性；`services/settings/config.rs` 保存启动策略、全局热键、媒体策略与自定义网络站点。原生状态和检测结果仅保存在 TanStack Query，不向多个 Zustand 仓库复制。

## 存储和权限

所有应用写入限定 D 盘，重解析点被拒绝。素材按类型与内容 SHA256 寻址，协议只接受摘要 ID；图片实际解码、字体解析字形、视频范围响应不超过 16MiB。字体仅在应用中加载，不安装系统字体。旧 IndexedDB 壁纸仍可选择使用。

启动项只能修改 `HKCU/.../Run/XinjingDesktop`。PawnIO 固定为官方 2.2.0，SHA256、有效 Authenticode 和发布者同时检查；提权助手再次验证并备份后执行。开发验收不写注册表、不安装驱动，不模拟鼠标或修改显示器颜色。驱动的恢复入口是反向装卸；已有其他版本不能声称自动精确还原。

清缓存保留下载成品、偏好和系统操作备份；占用文件跳过。重置只归档 `settings/tools/webview/logs/reports/profile/tmp`，包括便携启动器自己的 D 盘进程配置与临时目录，不动同目录的其他文件。备份与助手位于数据目录同级 D 盘 `.xinjing-maintenance`；数据锁防止双实例。助手等待原宿主退出，再操作文件；界面没有就绪时尝试回滚。重置应用数据不会撤销 Windows 系统修改。

## 热键和媒体

工具页不再独立注册准心或监测热键。录制最长 25 秒，原生 30 秒兜底；关闭录制/失焦/卸载恢复。保存前实际试注册，失败保留原配置并报告冲突。连点器必须先手动启用，Esc 急停；滤镜开启热键不能代替本次启动的逐项授权。

媒体动作使用 Windows GlobalSystemMediaTransportControlsSessionManager，操作等待播放器 ACK；无会话时明确不可用。不注入媒体键，避免拦截同键后的反馈循环。默认实体媒体键留给 Windows。独立桌面岛只能读自身状态、控制三种媒体动作和恢复主窗口，没有设置、文件和系统写权限。

## 更新与签名

更新源：`https://github.com/surgar04/m78deguren/releases/latest/download/xinjing-update.json`。无签名清单的 404 显示尚未发布，不伪称已经最新。清单的 exact UTF8 payload 使用 Ed25519 签名，应用只包含公钥；应用标识、仓库、平台、通道、版本、下载 URL、长度及 SHA256 全部验证，拒绝降级、任意下载地址和超长响应。自动更新只检查/准备，不自动替换。

固定 GitHub 源使用独立连接池，支持 Windows 系统代理与环境代理，重定向仅允许 GitHub 及其发布附件域名。自定义网络站点和普通下载继续使用公网 DNS 校验，不通过这个受信客户端请求任意地址。

发布者执行 `dev.ps1 desktop:bundle` 后，在相同 D 盘环境运行 `node scripts/sign-release.ts`。私钥只放 `.local/release-signing/ed25519-private.pem`，不得提交或上传。发布附件包括版本 EXE、便携 ZIP、`xinjing-update.json` 和 `SHA256SUMS.txt`。更新助手保留原 EXE，并在启动就绪检查失败时尝试恢复。

## 验证入口

- `dev.ps1 check`：格式、ESLint、严格 TS、Vitest、Rust 格式/Clippy/单测。
- `scripts/verify-settings-native.ps1`：PowerShell 语法、维护函数 D 盘夹具、真实只读启动项/PawnIO/WinRT 检测。
- `dev.ps1 exec node scripts/smoke-settings.ts`：连接独立 D 盘数据档案的 CDP 桌面实例，验证六栏目、六语言、持久化、导航、热键录制、真实检测及桌面岛，不执行系统修改。

这些验证不等同于实际安装/卸载驱动、变更 Windows 启动项、真实清除用户数据或跨版本更新验收；后者只在用户明确确认的应用运行会话中执行。
